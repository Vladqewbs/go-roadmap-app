# Трекер роадмапа Go

Уютное PWA-приложение для подготовки к стажировке по Golang. Работает на iPhone и Linux-ноутбуке, хранит прогресс локально, считает серию занятий, ведёт практику по темам и умеет синхронизироваться между устройствами через приватный GitHub Gist.

**Рабочее приложение:** https://vladqewbs.github.io/go-roadmap-app/

Исходники живут в этом приватном репозитории. Публикация сделана через публичное зеркало `Vladqewbs/go-roadmap-app`: GitHub Pages на бесплатном плане не работает для приватных репозиториев. При обновлении приложения измените файлы здесь, затем выполните `./deploy.sh` — скрипт скопирует файлы в зеркало и запушит их, после чего Pages пересоберётся автоматически.

## Возможности

- 8 этапов роадмапа в виде аккордеона: задачи, прогресс-бары и счётчики.
- Отдельный чек-лист минимума к собеседованию.
- Заметки к каждому этапу с автосохранением.
- Практика на LeetCode по 15 темам: массивы, строки, хеш-таблицы, два указателя, окно, бинарный поиск, списки, стек, деревья, графы, динамика, бэктрекинг, кучи, SQL и конкурентность.
- Кнопка «Дай мне задачу» — случайная нерешённая задача с темой и уровнем.
- Статистика LeetCode по нику: всего решено, Easy / Medium / Hard, рейтинг.
- 22 ачивки за прогресс, серию, практику и синхронизацию.
- Серия занятий и мини-календарь активности за 14 дней.
- Совет дня — небольшая подсказка, которая меняется каждый день.
- Светлая и тёмная тема, по умолчанию используется системная.
- Экспорт и импорт JSON без токена и интернета.
- Синхронизация через GitHub Gist с разрешением конфликтов по `updatedAt`.
- Офлайн-режим через service worker.
- Только HTML, CSS и JavaScript. Без сборщиков, библиотек и CDN.

## Локальный запуск

Из папки проекта:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. На `localhost` service worker тоже работает. Открытие `index.html` двойным кликом (`file://`) не позволит зарегистрировать service worker, но основные функции приложения будут работать.

## Публикация

Основной репозиторий приватный, а GitHub Pages на бесплатном плане работает только для публичных репозиториев. Поэтому статика публикуется из публичного зеркала `Vladqewbs/go-roadmap-app`.

Обновление приложения:

```bash
./deploy.sh
```

Скрипт клонирует зеркало во временную папку, копирует туда файлы проекта, коммитит и пушит. GitHub Pages пересобирается примерно за полминуты.

Проверить статус сборки:

```bash
gh api repos/Vladqewbs/go-roadmap-app/pages/builds/latest --jq .status
```

Если делаете форк с нуля: создайте публичный репозиторий, включите в нём **Settings → Pages → Deploy from a branch → main → / (root)** и загрузите файлы из корня проекта. GitHub Pages отдаёт сайт по HTTPS, а это обязательное условие для установки PWA и работы service worker. Секретов в файлах нет: токен вводится только в интерфейсе и сохраняется в localStorage устройства.

## Практика и LeetCode

Вкладка **Практика** содержит задачи, сгруппированные по темам. У каждой задачи есть отметка «решено», уровень сложности и ссылка на LeetCode. Прогресс по темам и общий счётчик сохраняются локально и синхронизируются через Gist.

Кнопка **«Подобрать задачу»** выбирает случайную нерешённую задачу. Её можно сразу открыть на LeetCode или отметить решённой.

### Статистика аккаунта

1. Откройте вкладку **Практика**.
2. Введите публичный ник LeetCode в поле **Ник на LeetCode**.
3. Нажмите **Подключить**.

Приложение обращается к публичному стороннему API (`alfa-leetcode-api.onrender.com`, при сбое — резервные зеркала), потому что официальный API LeetCode не отдаёт данные браузеру из-за CORS. Токен не нужен, но:

- профиль должен быть публичным;
- первый запрос может занять до 30 секунд (бесплатный хостинг «просыпается»);
- если API недоступен, отметки «решено» продолжают работать вручную, а статистика покажет последние сохранённые значения;
- статистика обновляется автоматически, если ей больше 6 часов.

Ник и статистика сохраняются в состоянии приложения и переносятся через Gist. Сам ник уходит только на публичный API LeetCode.

## Ачивки и серия

Ачивки открываются автоматически при изменении прогресса: задачи роадмапа, закрытые этапы, чек-лист, практика, Hard-задачи, SQL, конкурентность, заметки, серия и синхронизация. Всего 22 награды; дата открытия сохраняется.

Серия считается по локальной дате устройства: каждое отмеченное действие добавляет активность в текущий день. Если пропустить день, серия начинается заново. Календарь в карточке серии показывает последние 14 дней.

## Создание GitHub-токена

Нужен fine-grained personal access token с правом на Gist.

1. Откройте GitHub → **Settings**.
2. Внизу слева: **Developer settings**.
3. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
4. Придумайте имя, например `go-roadmap-sync`, и выберите срок действия.
5. В разделе **Account permissions** найдите **Gists** и установите **Read and write**.
6. Нажмите **Generate token** и сразу скопируйте токен.

Токен выглядит примерно так: `github_pat_...`. Вставляйте его в поле «GitHub-токен» в настройках приложения. Не публикуйте токен, не вставляйте его в код и не добавляйте в репозиторий. Если токен попал в чужие руки — отзовите его на GitHub и создайте новый.

## Подключение синхронизации

1. Откройте приложение и перейдите на вкладку **Ещё**.
2. Вставьте токен в поле **GitHub-токен**.
3. Поле **ID Gist** можно оставить пустым.
4. Нажмите **Подключить**.

Если ID Gist пустой, приложение отправит `POST https://api.github.com/gists` и создаст **приватный** Gist с файлом `roadmap.json`. ID автоматически появится в поле и сохранится в localStorage этого устройства.

Если ID уже указан, приложение подключится к существующему Gist. При старте и при нажатии «Синхронизировать сейчас» оно сначала делает `GET`, а затем:

- если `updatedAt` в Gist больше локального — загружает данные из Gist;
- если локальный `updatedAt` больше — отправляет локальную версию через `PATCH`;
- если время совпадает — отправляет актуальное состояние в Gist.

После каждого изменения приложение ставит отправку в очередь с задержкой 1,5 секунды. Заметки сначала сохраняются локально через 500 мс после окончания ввода.

Статусы в интерфейсе:

- **Синхронизировано** — данные в Gist актуальны.
- **Синхронизация…** — идёт запрос к GitHub.
- **Ошибка: проверьте токен / сеть** — запрос не удался; данные остались на устройстве.

Используемые заголовки:

```http
Authorization: Bearer {token}
Accept: application/vnd.github+json
```

## Второе устройство

1. Откройте то же приложение на втором устройстве.
2. Перейдите в **Ещё**.
3. Введите **тот же токен**.
4. Вставьте **ID Gist** с первого устройства. Не оставляйте поле пустым, иначе будет создан второй Gist.
5. Нажмите **Подключить**.
6. При запуске и синхронизации приложение сравнит `updatedAt` и подтянет более новую версию.

Если оба устройства были офлайн и изменили данные независимо, победит версия с большим `updatedAt`. Приложение не выполняет слияние отдельных задач. Для важных изменений периодически делайте экспорт JSON.

## Установка на iPhone

1. Откройте опубликованный сайт в **Safari**. Именно Safari, не Chrome и не встроенный браузер другого приложения.
2. Нажмите кнопку **Поделиться** (квадрат со стрелкой).
3. Выберите **На экран «Домой»**.
4. Нажмите **Добавить**.

Приложение откроется в отдельном окне без адресной строки, как обычное приложение. После первого онлайн-запуска оно работает офлайн. Не очищайте данные сайта в Safari и не удаляйте приложение с домашнего экрана без экспорта, иначе localStorage может быть удалён.

## Установка на Linux

### Chrome / Chromium / Edge

1. Откройте сайт по HTTPS.
2. Нажмите значок установки в адресной строке или откройте меню браузера.
3. Выберите **Установить приложение** (в некоторых версиях — **Установить Go Roadmap** или **Install app**).
4. Приложение появится в меню приложений и на панели задач.

### Firefox

В большинстве версий Firefox для Linux нет полноценной установки PWA в отдельном окне. Можно:

- открыть меню → **Дополнительные инструменты** → **Создать ярлык** (если пункт доступен в вашей версии), чтобы получить ярлык на сайте;
- либо просто добавить страницу в закладки и открывать её в браузере.

Для режима standalone с иконкой в системе удобнее Chrome, Chromium или Edge.

## Экспорт и импорт

- **Экспорт JSON** скачивает файл `go-roadmap-YYYY-MM-DD.json` с задачами, практикой, ачивками, заметками, серией, статистикой LeetCode, темой и чек-листом.
- **Импорт JSON** заменяет текущие данные содержимым файла после подтверждения.
- Импорт и экспорт не требуют токена и работают полностью офлайн.
- Токен и ID Gist в экспорт не попадают.

Экспорт — хорошая резервная копия перед сбросом браузера, переустановкой iOS-приложения или крупными изменениями.

## Иконки

Готовые `icon-192.png` и `icon-512.png` уже лежат в проекте. Чтобы перегенерировать их:

1. Откройте `generate-icons.html` в браузере.
2. Нажмите **Скачать 192 px** и **Скачать 512 px**.
3. Положите файлы `icon-192.png` и `icon-512.png` в корень проекта.
4. Увеличьте `CACHE_NAME` в `sw.js`, задеплойте изменения и переустановите PWA.

## Как устроены данные

Всё состояние хранится одним объектом в localStorage под ключом `go-roadmap-v1`:

```json
{
  "version": 2,
  "tasks": { "basics:0": true },
  "notes": { "basics": "Повторить слайсы" },
  "checklist": { "min-0": true },
  "practice": { "two-sum": true, "print-in-order": true },
  "activity": { "2026-11-13": 3 },
  "achievements": { "first-step": "2026-11-13T12:00:00.000Z" },
  "leetcode": {
    "username": "username",
    "total": 120,
    "easy": 60,
    "medium": 50,
    "hard": 10,
    "ranking": 250000,
    "syncedAt": "2026-11-13T12:05:00.000Z"
  },
  "syncedOnce": true,
  "theme": "dark",
  "updatedAt": "2026-11-13T12:00:00.000Z"
}
```

Токен и ID Gist хранятся отдельно, в localStorage под ключом `go-roadmap-sync-v1`, и никогда не попадают в state, Gist или экспорт.

Роадмап, чек-лист, темы практики и ачивки заданы массивами `ROADMAP`, `CHECKLIST_MIN`, `PRACTICE` и `ACHIEVEMENTS` в начале скрипта в `index.html`. Заголовки, недели, задачи и подборки можно менять прямо там. ID задач роадмапа строятся как `id этапа:индекс задачи`; при вставке задачи в середину списка старые отметки могут сдвинуться. Практика хранится по slug задачи, поэтому перестановка задач внутри темы безопасна.

Старые резервные копии с полем `startDate` импортируются нормально: незнакомые поля игнорируются, дата больше не используется.

## Офлайн и обновления

`sw.js` кэширует `index.html`, manifest и иконки. Навигационные запросы идут сначала в сеть, поэтому при наличии интернета вы получаете свежую версию, а без него — сохранённую копию. Статистика LeetCode и синхронизация Gist, разумеется, требуют сети; всё остальное работает офлайн.

Если вы изменили файлы приложения:

1. Увеличьте `CACHE_NAME` в `sw.js`, например с `go-roadmap-v5` на `go-roadmap-v6`.
2. Задеплойте изменения.
3. Обновите страницу два раза или перезапустите установленное PWA.

## Частые проблемы

**«Ошибка: проверьте токен / сеть»**

- Проверьте интернет.
- Убедитесь, что токен скопирован полностью и не истёк.
- Проверьте право **Gists: Read and write**.
- Убедитесь, что ID Gist принадлежит тому же аккаунту GitHub, что и токен.
- Если Gist удалён, введите новый ID или нажмите «Подключить» с пустым полем ID.

**Статистика LeetCode не загружается**

- Проверьте, что профиль публичный и ник написан без ссылки и лишних символов.
- Публичный API иногда перегружен или «просыпается» до 30 секунд. Повторите через минуту.
- Отметки «решено» в темах работают независимо от статистики: их можно ставить вручную.
- Если счётчик показывает старые данные, нажмите **Обновить**.

**Создался второй Gist**

Поле ID Gist было пустым на втором устройстве. Откройте Gist с первого устройства, скопируйте его ID и подключитесь к нему. Лишний Gist можно удалить на GitHub.

**Данные не появились на втором устройстве**

Нажмите **Синхронизировать сейчас** на обоих устройствах. Проверьте, что системное время устройств корректно: конфликты решаются по `updatedAt`.

**На iPhone нет пункта «На экран „Домой“»**

Сайт должен быть открыт именно в Safari по HTTPS. Встроенные браузеры приложений и Chrome на iOS могут не показывать этот пункт.

**GitHub отвечает 403**

Возможно, исчерпан лимит GitHub API или у токена недостаточно прав. Подождите и проверьте настройки токена.

## Приватность

- Прогресс, практика, ачивки и серия хранятся в localStorage браузера.
- При подключённом Gist данные отправляются только в GitHub API по HTTPS.
- Ник LeetCode и статистика решений отправляются на публичный сторонний API LeetCode; токены туда не передаются.
- Токен и ID Gist не вшиты в код и не синхронизируются между устройствами.
- Без токена приложение полностью локальное, кроме необязательного запроса статистики LeetCode.
