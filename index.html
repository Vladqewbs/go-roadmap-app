    Резервная копия

    Экспорт и импорт

    Работает без токена и интернета. JSON содержит прогресс, практику, ачивки, заметки и чек-лист.

    Очистит задачи, практику, ачивки, заметки и чек-лист. Тема оформления и ник LeetCode останутся.

    Как это устроено

    Без потерь

    • Каждое изменение сразу сохраняется в localStorage.
    • Без сети приложение продолжает работать, а данные остаются на устройстве.
    • При конфликте побеждает версия с большим updatedAt.
    • Ник LeetCode и статистика решений тоже переносятся через Gist.
    • Для второго устройства используйте тот же токен и ID Gist.
