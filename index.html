    Данные и устройства

    Настройки

    Подключите приватный Gist, чтобы переносить прогресс между iPhone и ноутбуком.

    GitHub Gist

    Синхронизация

    Токен и ID Gist хранятся только в localStorage этого браузера. В экспорт они не попадают.

    Fine-grained token с правом Gists: Read and write.
    Если пусто, при подключении будет создан новый приватный Gist с файлом roadmap.json.
    Локально

    Данные пока хранятся только на этом устройстве.

    При запуске приложение сначала читает Gist. Если поле updatedAt там больше, данные подтягиваются. Иначе изменения отправляются в Gist.

    Резервная копия

    Экспорт и импорт

    Работает без токена и интернета. JSON содержит прогресс, заметки, дату старта и чек-лист.

    Очистит задачи, заметки и чек-лист. Дата старта и тема оформления останутся.

    Как это устроено

    Без потерь

    • Каждое изменение сразу сохраняется в localStorage.
    • Без сети приложение продолжает работать, а данные остаются на устройстве.
    • При конфликте побеждает версия с большим updatedAt.
    • Для второго устройства используйте тот же токен и ID Gist.
